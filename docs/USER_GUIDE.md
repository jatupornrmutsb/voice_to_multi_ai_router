# คู่มือการใช้งานทีละขั้นตอน — Voice to Multi-AI Router

> ภาค ก ติดตั้งและทดสอบครั้งแรก · ภาค ข ใช้งานประจำวัน · ภาค ค ตัวอย่าง · ภาค ง แก้ปัญหา · ภาค จ ความปลอดภัย
> ภาพรวมระบบ: [README](../README.md) · รายละเอียดความปลอดภัย: [SECURITY.md](../SECURITY.md)

หน้าเว็บมี 4 ส่วน (เรียงจากบนลงล่าง):

1. **งานเบื้องหลัง / คำตอบที่ดึงกลับ** — การ์ดสถานะ ⏳/✅/❌ พร้อมคำตอบ
2. **พูดหรือพิมพ์คำสั่ง** — ปุ่มไมค์, กล่องข้อความ, Auto Send, ส่งเมื่อหยุดพูด (ตั้งเวลาได้), รอพูดยืนยัน
3. **ผลลัพธ์** — สถานะการส่งล่าสุด
4. **เลือกเครื่องมือ** — ปุ่มพร้อมป้าย 🟢 ฟรี · 🟡 ฟรีจำกัด/ใช้สิทธิ์ที่มี · 🔴 ใช้โควตา Claude

## ภาค ก — ติดตั้งและทดสอบครั้งแรก

### ขั้นที่ 1: เตรียมเครื่อง

- ติดตั้ง **Python 3.10+** จาก <https://www.python.org/downloads/> — ตอนติดตั้ง **ติ๊ก "Add python.exe to PATH"**
- ใช้ **Google Chrome** หรือ **Microsoft Edge**
- ติดตั้งและล็อกอินโปรแกรม AI ที่จะใช้ให้เรียบร้อย (Antigravity, VS Code, Cursor, Claude, Gemini ฯลฯ)

### ขั้นที่ 2: ขอ Gemini API Key (ไม่บังคับ แต่แนะนำ)

> **แพ็กเกจ Gemini Pro ≠ Gemini API Key** — แพ็กเกจ Pro ใช้กับแอป/เว็บ Gemini เท่านั้น โปรแกรมนี้ใช้ API Key ซึ่งขอได้ **ฟรี** ด้วยบัญชี Google
>
> ไม่มี Key ก็ใช้งานได้ด้วยการกดปุ่มเลือกเครื่องมือ — Key ใช้กับปุ่ม 🤖 อัตโนมัติ, ถาม Gemini และ Gemini CLI

1. เปิด <https://aistudio.google.com/apikey> แล้วล็อกอินบัญชี Google
2. ครั้งแรกจะมีหน้ายอมรับเงื่อนไข → อ่านแล้วกดยอมรับ
3. กด **Create API key** → กด **Copy** (ขึ้นต้นด้วย `AIza...`)
4. **เก็บ Key เป็นความลับ** — อย่าวางในแชต อีเมล เอกสาร หรือ repo ใดๆ ถ้าหลุดให้ลบทิ้งที่หน้าเดิมแล้วสร้างใหม่

### ขั้นที่ 3: ติดตั้ง

1. ดาวน์โหลด repo (**Code → Download ZIP**) แล้วแตกไฟล์ไว้ในไดรฟ์ของเครื่อง เช่น `%USERPROFILE%\voice_to_multi_ai_router`
   (ไม่แนะนำ Google Drive / OneDrive)
2. ดับเบิลคลิก **`install.bat`**
3. ตอบคำถาม (กด Enter เพื่อข้ามได้):
   - **Gemini API Key** — วาง Key จากขั้นที่ 2 (ตัวอักษรไม่แสดงบนจอ)
   - **โฟลเดอร์โปรเจกต์** ที่ให้ Claude Code / Gemini CLI ทำงาน — แนะนำโปรเจกต์ที่อยู่ใน git
4. รอจนขึ้น "ติดตั้งเสร็จแล้ว!" พร้อมรายการเครื่องมือที่พบ (🟢 พร้อม / ⚪ ติดตั้งแล้วแต่ยังไม่เปิด / ⚫ ไม่ได้ติดตั้ง)

### ขั้นที่ 4: ทดสอบครั้งแรก

1. ดับเบิลคลิก **AI Router** บน Desktop → หน้าต่างสีดำขึ้น — **เปิดทิ้งไว้** (ถ้า Windows Firewall ถาม กด Cancel ได้ — ระบบใช้เฉพาะในเครื่อง)
2. ประมาณ 3 วินาที เบราว์เซอร์จะเปิดหน้า **🎙 AI Router** เอง (ถ้าไม่เปิด พิมพ์ `http://127.0.0.1:5000` ใน Chrome/Edge)
3. ส่วน **3. ผลลัพธ์** ต้องขึ้น "พร้อมใช้งาน — พบ N เครื่องมือในเครื่อง"
4. **ทดสอบไมค์:** กด 🎤 → เบราว์เซอร์ถามสิทธิ์ไมโครโฟน → **Allow** → พูด "สวัสดีครับ" → ข้อความต้องขึ้นในกล่อง
5. **ทดสอบถาม Gemini (ถ้ามี Key):** กดปุ่ม **ถาม Gemini (เร็ว)** → พิมพ์ "ตอบคำว่า pong" → **ส่ง ▶** → คำตอบขึ้นในส่วน **1** และ **3**
6. **ทดสอบวางข้อความ:** เปิดโปรแกรม AI ตัวใดตัวหนึ่ง → กดปุ่มของโปรแกรมนั้น → **ไม่ติ๊ก** Auto Send → **ส่ง ▶** → ข้อความต้องไปอยู่ในช่องพิมพ์ของโปรแกรมนั้นโดยยังไม่ถูกส่ง

## ภาค ข — ใช้งานประจำวัน

1. **เปิดระบบ:** ดับเบิลคลิก **AI Router** บน Desktop (หน้าเว็บเปิดเอง)
2. **เปิดโปรแกรมปลายทาง** ที่จะใช้ (Claude Code / Gemini CLI ไม่ต้องเปิด — รันเบื้องหลัง)
3. **พูด:** กด 🎤 (หรือ `Alt+M`) แล้วพูด — หรือ **กดปุ่ม "ส่ง ▶" ค้างไว้แล้วพูด** ปล่อยปุ่ม = ส่งทันที
4. **เลือกเครื่องมือ:** กดปุ่ม (หรือ `Alt+0…9`) — หรือกด **🤖 อัตโนมัติ** ให้ Gemini เลือก (เลือกตัวฟรีก่อน 🟢 → 🟡 → 🔴 เว้นแต่พูดชื่อเครื่องมือ)
   - ปุ่มจาง = โปรแกรมยังไม่เปิด (เปิดแล้วรอ 15 วินาที ปุ่มจะสว่าง)
5. **เลือกโหมด:**
   - ☑ **Auto Send** = กด Enter ในโปรแกรมปลายทางให้ · ☐ = วางไว้ให้ตรวจก่อน (แนะนำช่วงแรก)
   - ☑ **ส่งเมื่อหยุดพูด** = พูดจบ เงียบตามเวลาที่ตั้ง (ช่องตัวเลขข้างตัวเลือก 0.5–10 วินาที ค่าเริ่มต้น 1.5) ส่งเอง — พูดช้า/หยุดคิดบ่อย ให้ตั้งนานขึ้น
   - ☑ **รอพูดยืนยัน** = ยังไม่ส่งจนกว่าจะยืนยัน (ปุ่มเปลี่ยนเป็น **ยืนยันส่ง** สีเหลือง และไมค์ฟังต่อ)
     - พูดคำยืนยัน เช่น **"ok / โอเค / ตกลง / ดำเนินการ / ยืนยัน / ทำต่อ / ส่งเลย"** → ส่งทันที (คำลงท้าย "ครับ/ค่ะ/นะ" ไม่มีผล)
     - พูดคำยกเลิก เช่น **"ยกเลิก / ไม่เอา / ไม่ต้อง"** → ล้างข้อความ แล้วรอรับข้อความใหม่
     - พูดอย่างอื่น → ถือเป็น **ข้อความใหม่** แทนข้อความเดิม แล้วรอยืนยันอีกครั้ง
     - กดปุ่ม **ยืนยันส่ง** หรือ `Ctrl+Enter` = ยืนยันด้วยมือ
     - แก้รายการคำยืนยัน/คำยกเลิกได้ในช่องใต้ตัวเลือก (คั่นด้วย `,`) — ต้องพูดคำนั้นเป็นวลีเดียว ประโยคยาวที่มีคำนี้ปนอยู่จะไม่นับ
6. **ส่ง:** **ส่ง ▶** หรือ `Ctrl+Enter`
   - **อย่าขยับเมาส์/พิมพ์** ประมาณ 1 วินาทีระหว่างระบบสลับหน้าต่างและวางข้อความ
7. **ดูคำตอบ** ในส่วน **1. งานเบื้องหลัง** — การ์ด ⏳ → ✅ พร้อมคำตอบ · กด **หยุด** / **คัดลอก** ได้
   - เครื่องมือที่ดึงคำตอบกลับได้: ถาม Gemini, Gemini CLI, Claude Code, Antigravity ทุกแบบ, VS Code · Claude
8. **ปิดระบบ:** ปิดหน้าต่างสีดำ

**ประหยัดค่าใช้จ่าย:** งานทั่วไปใช้ 🟢 ถาม Gemini / Gemini CLI · งานเขียนโค้ดใช้ 🟡 Antigravity · ใช้ 🔴 Claude เฉพาะงานที่ต้องการ Claude จริงๆ

## ภาค ค — ตัวอย่างการสั่งงาน

### ตัวอย่าง 1: ถามตอบเร็ว (ฟรี)

1. กดปุ่ม **🟢 ถาม Gemini (เร็ว)**
2. พูด: "Python กับ JavaScript ต่างกันอย่างไร สรุป 3 ข้อ" → **ส่ง ▶**
3. คำตอบขึ้นในส่วน **3. ผลลัพธ์** และการ์ดในส่วน **1** ภายในไม่กี่วินาที

### ตัวอย่าง 2: ค้นข้อมูล/สรุปด้วย Gemini CLI (ฟรี, เบื้องหลัง)

1. กดปุ่ม **🟢 Gemini CLI**
2. พูด: "ค้นข่าวเรื่อง AI ในการศึกษาล่าสุด แล้วสรุปเป็น 5 ข้อ" → **ส่ง ▶**
3. ดูการ์ด ⏳ Gemini CLI ในส่วน **1** → เสร็จแล้วผลสรุปขึ้นในการ์ด

### ตัวอย่าง 3: เขียนโค้ดด้วย Antigravity (ใช้สิทธิ์บัญชี Google)

1. เปิด Antigravity IDE พร้อมโปรเจกต์ → กดปุ่ม **🟡 Antigravity IDE** · ติ๊ก **Auto Send**
2. พูด: "เขียนฟังก์ชันอ่านไฟล์ CSV แล้วคืนค่าเป็น list ของ dict" → **ส่ง ▶**
3. Agent ใน Antigravity เริ่มทำงาน — การ์ดในส่วน **1** แสดงความคืบหน้าและคำตอบเมื่อเสร็จ

### ตัวอย่าง 4: ให้ Gemini เลือกเอง แบบตรวจก่อนส่ง

1. กดปุ่ม **🤖 อัตโนมัติ** · ไม่ติ๊ก Auto Send
2. พูด: "ให้ Antigravity ช่วยรีแฟกเตอร์ไฟล์ main.py" → **ส่ง ▶**
3. แผงแสดง "Gemini เลือก: Antigravity" + ปุ่มนั้นมีกรอบเส้นประ + ข้อความเหลือ "รีแฟกเตอร์ไฟล์ main.py"
4. ถูกต้อง → **ยืนยันส่ง ▶** · ผิด → กดปุ่มเครื่องมือที่ต้องการแทน แล้วกดส่ง

### ตัวอย่าง 5: งานใหญ่ด้วย Claude Code (ใช้โควตา Claude)

1. กดปุ่ม **🔴 Claude Code**
2. พูด: "รันเทสต์ทั้งหมดแล้วสรุปว่าอันไหนล้ม" → **ส่ง ▶**
3. การ์ด ⏳ Claude Code ในส่วน **1** — ทำงานอื่นต่อได้เลย · เสร็จแล้วกางผลลัพธ์ให้อัตโนมัติ (บันทึกไว้ใน `logs\` ด้วย)

### ตัวอย่าง 6: สั่งงานแบบไม่แตะคีย์บอร์ด

1. กดปุ่มเครื่องมือ · ติ๊ก **Auto Send** และ **ส่งเมื่อหยุดพูด**
2. กด 🎤 แล้วพูดคำสั่ง → หยุดพูด
3. เมื่อเงียบครบเวลาที่ตั้ง (ค่าเริ่มต้น 1.5 วินาที) ระบบส่งและกด Enter ให้เอง

### ตัวอย่าง 7: ไม่แตะคีย์บอร์ด แต่ขอยืนยันก่อนส่ง (ปลอดภัยกว่า)

1. ติ๊ก **Auto Send**, **ส่งเมื่อหยุดพูด** และ **รอพูดยืนยัน**
2. กด 🎤 แล้วพูด: "สรุปข่าว AI วันนี้ 3 ข้อ" → หยุดพูด → ปุ่มกลายเป็น **ยืนยันส่ง** สีเหลือง
3. ตรวจข้อความในกล่อง แล้วพูด **"ตกลงครับ"** → ส่งทันที
   - ถอดเสียงผิด → พูด **"ยกเลิก"** แล้วพูดใหม่ หรือพูดประโยคใหม่ไปเลย (แทนที่ข้อความเดิมอัตโนมัติ)

## ภาค ง — แก้ปัญหาที่พบบ่อย

| อาการ | สาเหตุ | วิธีแก้ |
| :--- | :--- | :--- |
| `install.bat` แจ้งไม่พบ Python | ยังไม่ติดตั้ง หรือไม่ได้ติ๊ก "Add to PATH" | ติดตั้ง Python ใหม่โดยติ๊ก "Add python.exe to PATH" แล้วรัน `install.bat` ใหม่ |
| หน้าต่างสีดำขึ้น `DISPATCH_TOKEN ไม่ได้ตั้งหรือสั้นเกินไป` | ยังไม่ได้ติดตั้ง หรือเพิ่งติดตั้งในหน้าต่างเดิม | รัน `install.bat` แล้วเปิด AI Router ใหม่ |
| หน้าเว็บขึ้น ❌ ติดต่อเซิร์ฟเวอร์ไม่ได้ | ปิดหน้าต่างสีดำไปแล้ว | เปิด AI Router ใหม่ |
| ❌ unauthorized | Token เปลี่ยนแต่ยังไม่รีสตาร์ต | ปิดหน้าต่างสีดำ แล้วเปิด AI Router ใหม่ และรีเฟรชหน้าเว็บ |
| ปุ่ม 🤖 อัตโนมัติจาง / ไม่มีปุ่ม Gemini CLI, ถาม Gemini | ยังไม่ได้ตั้ง `GEMINI_API_KEY` | รัน `install.bat` ใหม่ หรือ `setx GEMINI_API_KEY "<Key>"` แล้วเปิด AI Router ใหม่ |
| ❌ Gemini ตอบช้าเกินไป / มีผู้ใช้มาก / โควตาเต็ม | Gemini ฝั่ง Google ไม่ว่าง หรือโควตาฟรีหมด | รอสักครู่แล้วลองใหม่ หรือกดปุ่มเครื่องมือเองแทน |
| ❌ Gemini API Key ไม่ถูกต้อง | Key ผิดหรือถูกลบ | สร้าง Key ใหม่แล้ว `setx GEMINI_API_KEY "<Key ใหม่>"` |
| กด 🎤 แล้วขึ้น "ไม่ได้รับอนุญาตให้ใช้ไมโครโฟน" | กด Block ไว้ | คลิกไอคอนข้าง URL → Microphone → Allow → รีเฟรชหน้า |
| "เบราว์เซอร์นี้ไม่รองรับการถอดเสียง" | ใช้ Firefox หรือเบราว์เซอร์อื่น | เปิด `http://127.0.0.1:5000` ใน Chrome หรือ Edge |
| ถอดเสียงผิดเยอะ | ไมค์/เสียงรบกวน | พูดช้าลง ใกล้ไมค์ แล้วแก้ข้อความในกล่องก่อนส่ง |
| ❌ ข้อความยาวเกิน 8,000 ตัวอักษร | จำกัดเพื่อความปลอดภัย | แบ่งคำสั่งเป็นหลายส่วน |
| ปุ่มจางตลอดทั้งที่เปิดโปรแกรมแล้ว | ชื่อหน้าต่างไม่ตรงกับที่ตั้งไว้ | ดูชื่อหน้าต่างใน Task Manager แล้วแก้ `match` ใน `TOOLS` ของ `local_dispatcher.py` |
| ❌ ไม่พบหน้าต่าง | โปรแกรมยังไม่เปิด | เปิดโปรแกรมก่อนส่ง |
| ❌ สลับไปหน้าต่างไม่สำเร็จ | Windows บล็อกการสลับหน้าต่าง | คลิกหน้าต่างปลายทางหนึ่งครั้ง แล้วลองใหม่ |
| ข้อความไปผิดช่อง (เช่น ไปอยู่ในไฟล์โค้ด) | ปุ่มลัดเปิดแชตไม่ตรงกับเวอร์ชันโปรแกรม | ลองกดปุ่มลัดด้วยมือ แล้วแก้ `hotkey` ใน `TOOLS` |
| Antigravity IDE: ข้อความไม่เข้าแชต Agent | ช่องพิมพ์ยังวาดไม่เสร็จตอนวาง | เพิ่ม `hotkey_wait` ของ `antigravity_ide` (เช่น 1.2 → 2.0) |

## ภาค จ — ข้อควรระวังด้านความปลอดภัย

- ระบบนี้ **พิมพ์ข้อความลงโปรแกรมและรันเครื่องมือ AI บนเครื่องของคุณ** — ใช้บนเครื่องส่วนตัวเท่านั้น อย่าแก้ให้เครื่องอื่นเข้าถึงได้
- **Token และ API Key** เก็บใน Environment Variables ของผู้ใช้ — อย่าคัดลอกไปเครื่องอื่นหรือส่งให้ใคร แต่ละเครื่องควรใช้ Key ของตัวเอง
- **อย่าพูด/พิมพ์ข้อมูลลับ** (รหัสผ่าน ข้อมูลส่วนบุคคล) — เสียงถูกส่งไปถอดความที่ Google และข้อความในโหมด Gemini ถูกส่งไป Gemini API
- **โฟลเดอร์ `logs\`** เก็บคำสั่งและคำตอบของงานเบื้องหลัง — ลบได้ตามต้องการ และอย่าแนบไฟล์เหล่านี้ใน Issue
- **สิทธิ์ของเอเจนต์:** ถ้าเปิดให้แก้ไฟล์เองได้ (`acceptEdits`, `auto_edit`, โหมด agent) ให้ตั้ง `CLAUDE_WORKDIR` เป็นโปรเจกต์ที่อยู่ใน git เพื่อย้อนกลับได้ และอย่าตั้งเป็นโฟลเดอร์ระบบหรือโฟลเดอร์ของโปรแกรมนี้เอง
- **ถอนการติดตั้ง:** `uninstall.bat` ลบ Token, Key, ทางลัด และปุ่มลัด VS Code ที่ระบบเพิ่มไว้
